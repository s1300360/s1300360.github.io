Profile photo
-------------
A confirmed personal headshot was not available in the working files, so profile.svg is a polished monogram placeholder.
To use your own portrait later:
1. Put a portrait image in this folder and name it profile.jpg.
2. In index.html, replace: src="profile.svg" with src="profile.jpg".
Recommended crop: vertical 4:5, at least 800 x 1000 px.

GitHub Pages
------------
1. Create a GitHub repository named: YOURUSERNAME.github.io
2. Upload ALL files from this folder to the repository root.
3. Open Settings > Pages.
4. Set deployment source to the main branch / root folder if GitHub asks.
5. Your website will be available at https://YOURUSERNAME.github.io

Custom domain
-------------
A custom domain can be connected later through GitHub Pages settings.
